How we built this

LinkedIn licensee analysis — checked each major licensee for adviser hiring activity, new authorisation announcements, and restructuring signals
Practice principal age profiling — cross-referenced experienced pathway usage (4,212 advisers, typically older) with practice size and hiring patterns to estimate succession-ready practices
